# Blog Samples

이 글은 다양한 블로그 예시(차트, 표, 이미지 등)를 한 곳에 모은 통합 샘플입니다.

## Chart.js 예시

```chartjs
{
  "type": "line",
  "data": {
    "labels": ["January", "February", "March", "April", "May", "June", "July"],
    "datasets": [{
      "label": "# of bugs",
      "data": [65, 59, 80, 81, 56, 55, 40],
      "fill": false,
      "borderColor": "rgba(75,192,192,1)"
    }]
  }
}
```

## ECharts 예시

```echarts
{
  "title": {"text": "ECharts Getting Started Example"},
  "xAxis": {"data": ["Shirts", "Cardigans", "Chiffons", "Pants", "Heels", "Socks"]},
  "yAxis": {},
  "series": [{"name": "sales", "type": "bar", "data": [5, 20, 36, 10, 10, 20]}]
}
```

## Plotly.js 예시

```plotly
{
  "data": [
    {"x": [1, 2, 3, 4], "y": [10, 15, 13, 17], "type": "scatter"},
    {"x": [1, 2, 3, 4], "y": [16, 5, 11, 9], "type": "scatter"}
  ]
}
```
